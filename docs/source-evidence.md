# Recorded source-evidence inspection

The inspector replays seven unchanged zones-core reports over committed May
2026 metadata/derived fixtures. It is distinct from the four invented units
in the clock experiment. It emits no county scores, maps or candidate rankings.

Policy coverage (source_gate_ready), reference-field coverage
(publishable_source_ref_coverage), recorded assignment/geometry evidence and
context consistency are separate structural checks, not publication approval.
The four county records have zero connecting graph edges. Four caveated Census
internal points and zero population centers retain the false strong-claim
point-method gate. Zero selected/internal-point delta is not evidence of
population-center accuracy or zero uncertainty. Source references are frozen
recorded citations, not newly verified current law or GIS boundaries.

Input downloads preserve exact committed LF JSON bytes; source-custody.json
records source paths, byte sizes and SHA-256. Windows checkout CRLF is not the
canonical published hash. The build checks normalized working input against
its committed Git blob. No raw publisher payloads, national GIS cache, new
source acquisition, primary-byte verification, current-law revalidation or
fresh geometry overlay is included. Existing source caveats/attribution remain.
The native report bytes match the corresponding original zones-cli command.

Query example: cargo run --locked -p zones-web --bin zones-evidence -- fixtures/evidence-points.json.
Original: cargo run --locked -p zones-cli -- representative-point-report data/representative-points/us-county-seed-gazetteer.json.

Worker queries execute locally without source-law/GIS requests, uploads or
storage. Unknown fields/lenses and >64 KiB fail closed. Legal assignment,
scheduling, enactment, candidate recommendation, county-scorecard publication,
national-baseline and primary-verification authority remain false. Regional
program outcomes, population-center accuracy and current-law verification
remain unobserved. Pulse 04's publication/recommendation holds are unchanged.
